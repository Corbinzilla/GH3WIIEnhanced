GH3 Enhanced Is A Mod That Aims To Enhance The Gameplay On Guitar Hero 3 For The Wii

How To Install
  Prerequisits
    #1. A ripped copy of GH3 WII, you can get this from wherever, a recommended link to get the game is https://drive.google.com/drive/folders/1Qwatkm31zYjssPR9ey9CwauWSk7uQVJq?usp=sharing
    #2. Wii Dolphin installed and set up
  Instilation
    #1. Copy and paste the qb.pak.ngc file into DATA\files\pak in the directory of your ripped game and replace them.
    #2. Copy the files ui_sfx_50_note_streak and ui_sfx_100_note_streak into the DATA\files\sounds folder of your directory and replace them.
    #3. Set your path in Dolphin to the folder of the ripped files, from here you should be able to open the game in Dolphin, the game should show up as 0.00 Gigabytes and it should just work!
